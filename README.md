# Data Source

## DGCIS 2024–25 Inland Goods Movement

The project uses the official Government of India publication:

**Inter/Intra-State Movements/Flows of Goods by Rail, River and Air – 2024–25**

Primary focus: **Rail freight movement**

Official source:
https://www.dgciskol.gov.in/pub_inland.aspx

Publication:
https://www.dgciskol.gov.in/writereaddata/Downloads/20260227120851IT%20REPORT_2024_25_Final.pdf

## Why the dataset is used

The publication provides information that can support:

- State-wise freight analysis
- Inward and outward movement analysis
- Internal movement analysis
- Commodity-wise analysis
- Inter-state origin-destination analysis
- Freight concentration analysis

## Data handling

The complete government dataset is not duplicated in this repository. The official source is linked above so that the data can be obtained from its original publisher.

Before analysis, downloaded tables should be checked against the totals published in the official report.
